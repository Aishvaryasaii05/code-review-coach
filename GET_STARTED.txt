⚡ QUICK START (3 Steps)

1️⃣  Install dependencies:
    npm run setup

2️⃣  Add your API key:
    Edit backend/.env and set BOB_API_KEY=your_key_here
    Get key from: https://bob.ibm.com/admin/apikeys

3️⃣  Start the app:
    npm start

🛠️ ALTERNATIVE START METHODS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A - Automated launcher:
    node run-app.js

Option B - Bash script (Linux/Mac):
    chmod +x start.sh
    ./start.sh

Option C - Manual (2 terminals):
    Terminal 1: cd backend && npm start
    Terminal 2: cd frontend && python3 -m http.server 5500

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Can't connect to localhost:5500?
  → Make sure you ran 'npm start' and see the success message

"BOB_API_KEY is not set" error?
  → Edit backend/.env and add your key from bob.ibm.com/admin/apikeys

Port already in use?
  → Change PORT in backend/.env to a different number

Backend errors?
  → Make sure you ran 'npm run setup' first
