    GOOD TO KNOW

    Frequently asked questions.

    Everything you need to know before turning your next change into a clearer release.

    How does Code Review Coach work?

    Paste code or upload a supported file, choose the language, and select Review Code. The assistant analyzes the code for risks, quality issues, and practical fixes.

    What technology is used?

    The project uses a lightweight HTML, CSS, and JavaScript frontend with a Node.js backend. AI analysis is connected through the configured Groq or IBM watsonx integration.

    Which programming languages are supported?

    JavaScript, TypeScript, Python, Java, and other text-based source files can be reviewed. The selected language helps the assistant give more focused feedback.

    Can I create release notes from code changes?

    Yes. Paste a diff, changelog, commit list, or source change, select an audience, and generate organized release notes that are easier to share.

    Where can I find previous reviews?

    Use the History section to revisit saved code reviews and release notes. The Dashboard also summarizes review activity and common findings.
