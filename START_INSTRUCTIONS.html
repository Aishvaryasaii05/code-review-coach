⚠️ Server Not Running

The application servers need to be started. Follow the steps below.

1 Install Dependencies

Install the required Node.js packages:

cd backend && npm install
2 Configure API Key

Edit backend/.env and add your IBM Bob API key:

BOB_API_KEY=your_actual_api_key_here

Get your key from: bob.ibm.com/admin/apikeys

3 Start the Application

Run the automated launcher:

node run-app.js

Or manually in two terminals:

# Terminal 1 - Backend
cd backend && npm start

# Terminal 2 - Frontend
cd frontend && python3 -m http.server 5500
✓ Once Started

Access the application at: http://localhost:5500
