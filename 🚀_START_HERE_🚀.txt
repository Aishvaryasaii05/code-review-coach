⚡ THREE STEPS TO SUCCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open your terminal in this folder and run these commands:


1️⃣  INSTALL (one time only)
    ─────────────────────────────────────────────────────────────────
    npm run setup
    ─────────────────────────────────────────────────────────────────
    This installs all the required packages. Takes ~30 seconds.


2️⃣  CONFIGURE (one time only)
    ─────────────────────────────────────────────────────────────────
    Edit the file:  backend/.env
    
    Add your API key:  BOB_API_KEY=paste_your_key_here
    
    Get your key from:  https://bob.ibm.com/admin/apikeys
    ─────────────────────────────────────────────────────────────────


3️⃣  START
    ─────────────────────────────────────────────────────────────────
    npm start
    ─────────────────────────────────────────────────────────────────
    This starts both servers. Keep this terminal open!


🌐 THEN OPEN IN BROWSER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 ALTERNATIVE START METHODS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If "npm start" doesn't work, try:

Method A - Node script:
    node run-app.js

Method B - Bash script (Linux/Mac only):
    chmod +x start.sh
    ./start.sh

Method C - Manual (two separate terminals):
    Terminal 1:  cd backend && npm start
    Terminal 2:  cd frontend && python3 -m http.server 5500


🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "node: command not found"
   → Install Node.js from https://nodejs.org/ (need version 18+)

❌ "Cannot find module"
   → Run: npm run setup

❌ "BOB_API_KEY is not set"
   → Edit backend/.env and add your API key

❌ "EADDRINUSE" or "Port already in use"
   → Kill the process or change PORT in backend/.env

❌ "python3: command not found" (Windows)
   → Use "py -m http.server 5500" instead

❌ Browser shows "This site can't be reached"
   → Make sure you ran "npm start" and see success message
